## 作品概要
- **開発環境**：C++ / Siv3D / Visual Studio 2022
- **開発期間・人数**：2025年10月～2025年11月（制作期間：1ヶ月半） / 個人制作

## 特徴
- 農夫の思考アイコンに対応したキーを入力し、好感度を上げて出荷を回避するゲーム
- プレイヤーの入力に対するリアクション演出と、残り時間に応じた緊迫感のあるゲーム進行
- 感情変化や状態パラメータに連動した直感的なフィードバック設計

## 技術的工夫
### 1. イベント遅延制御による状態遷移の破綻防止（Pending機構）
リアクション演出の途中でタイムアップ等の画面遷移が割り込み、演出が不自然に中断されないために、発生したイベントを一時保留（Pending）し、アニメーション完了後に遷移を実行する処理を構築しました。

### 2. Request方式による描画とロジックの疎結合化
描画順序の管理や依存関係が複雑化するのを防ぐために、各マネージャーからUIManagerへ描画要求を送るだけに留め、UIManager側で描画キューを一括処理することで、ゲームロジックと描画処理の依存関係を完全に切り離し、UIの追加・変更が容易な保守性の高い設計を実現しました。

## 課題と解決策
- **課題：** リアクション判定の演出中に「タイムアップ」や「残り60秒切り（夕方への背景変化）」が発生した際、演出が強制中断されて画面表示やゲーム進行が破綻する現象が発生。
- **原因と解決：** アニメーション再生中であっても制限時間イベントが即座に状態遷移を実行していたことが原因でした。<br>
演出実行中（GetIsResultMoment）に発生したイベントは即座に画面を切り替えず、一度遅延フラグ（Pending）として一時保持する調停ロジックを構築。演出が完了したタイミングで安全に次の状態へ遷移させることで、演出の破綻がないスムーズなゲーム進行を実現しました。
